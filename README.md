# MGT-418 Convex Optimization - EPFL

Course materials and exercises for the Convex Optimization course at EPFL.

## Course Info

- **Lecturer:** Daniel Kuhn
- **Teaching Assistants:** Mengmeng Li, Jakob Nylof, Ehsan Sharifian, Buse Sen, Andrea Della Vecchia

## Topics Covered

- Convex Sets
- Convex Functions
- Convex Optimization Problems
- Lagrangian Duality
- Optimality Conditions
- Separation Theorems
- Conjugate Duality
- Optimization in Statistics & Machine Learning
- Convexifying Nonconvex Problems
- Robust Optimization
- Stochastic Programming

## Reference Book

**Stephen Boyd and Lieven Vandenberghe, *Convex Optimization*, Cambridge University Press, 2009**

An extremely well written and comprehensive textbook. The book along with supplementary material (exercises, lecture slides, and additional notes) can be downloaded for free from:

[http://www.stanford.edu/~boyd/cvxbook/](http://www.stanford.edu/~boyd/cvxbook/)
